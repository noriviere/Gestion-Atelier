Outillage

Chaque outil est décrit comme un arbre : l'outil principal, ses sous-ensembles, et les pièces d'usure montées sur chacun. Les pièces d'usure sont des articles du stock.

L'arborescence

{% droit_requis "outillage_consulter" %}

Le menu Outillage montre tous les outils principaux, dépliés. Dans l'arbre :

  • les lignes en gras sont des outils ou sous-ensembles ; un clic ouvre leur fiche ;
  • les lignes « 2 × PAT-G Patin taille G » sont les pièces d'usure : quantité montée, référence et désignation, avec le stock actuel (en rouge sous le mini) ;
  • Utilisé pour liste les produits dont la fiche utilise l'outil.

Une même pièce peut être montée sur plusieurs outils : par exemple un patin commun à plusieurs produits. Sa fiche article indique tous les outils qui l'utilisent.

La fiche d'un outil

Elle montre la composition de l'outil (ses sous-ensembles et pièces avec leur stock), sa description, et les produits fabriqués avec lui, avec un lien vers chaque fiche de production. Le fil d'Ariane remonte jusqu'à l'outil principal.

Sortir une pièce remplacée

{% droit_requis "stock_mouvements" %}

Sur la fiche d'un outil, chaque pièce d'usure a un champ de quantité et un bouton Sortir. Quand vous changez une pièce usée, saisissez la quantité prise en magasin (préremplie avec la quantité montée) puis Sortir : une sortie de stock est enregistrée sur l'article, avec l'outil en commentaire.

C'est la façon la plus rapide de tenir le stock à jour : pas besoin de chercher l'article.

Créer ou modifier un outil

{% droit_requis "outillage_modifier" %}

Boutons Nouvel outil, Modifier l'outil et ses pièces et Ajouter un sous-ensemble.

Code et nom
Obligatoires. Le code est unique : « OUT-N10-1 ».
Sous-ensemble de
Laissez « aucun » pour un outil principal ; choisissez l'outil parent pour un sous-ensemble. Un outil ne peut pas être rangé sous l'un de ses propres sous-ensembles.
Description
Texte libre affiché sur la fiche de l'outil.
Pièces d'usure montées
Choisissez l'article dans le stock et la quantité montée. Cochez retirer pour enlever une pièce de l'outil (l'article reste dans le stock). Trois lignes vides sont proposées ; enregistrez pour en obtenir d'autres.

Supprimer un outil

{% droit_requis "outillage_modifier" %}

En bas du formulaire de modification. La suppression emporte les sous-ensembles de l'outil ; une confirmation est demandée. Les articles restent dans le stock, et les fiches de production n'utilisent simplement plus cet outil.
